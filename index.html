Manifesto

github.com/diu-os/manifesto — epistemic charter, Apache-2.0. Living text: MANIFESTO.md. PDF v1.0.0 (Dec 2025) is a prior-art snapshot of an earlier stack. It is not the product.

§1.1 Truthfulness is the mission

DIU OS exists to maximize truthfulness.

It does not exist to maximize how interesting a result is, how fast a conclusion arrives, how many papers are produced, or how satisfied a user feels.

Trading truthfulness for any of those is a breach of this constitution.

Truthfulness here is the mission. It is not a stamp on an empirical run. What a run receives is a checkable status, relative to stated assumptions, the model, the computation, and the evidence.

These two sections are the public statement of constitution §1.1 and §1.2. The remaining parts are not on this page. The same text is on diu-os.com/#/about.

§1.2 What counts as evidence

The following count as evidence, in this order.

  1. A reproducible experiment.
  2. Formally verified mathematics.
  3. An independent replication.
  4. A statistical consensus, which has weight and is not final.

The following do not count as evidence.

  • The authority of a scientist, an institution, or an AI system.
  • The beauty of a theory.
  • Mathematical elegance without experimental support.
  • Consensus that has not been reproduced.

Which license comes first

Apache-2.0 and MIT cover different trees. They are not two bids for the same code.

Apache-2.0 is the license of the open core: the kernel and the manifesto. It is the one that matters when another lab links the checker. It keeps attribution, a NOTICE, and a patent grant. MIT stays on the contract snapshot, where it already ships. MIT on those contracts does not open the kernel. Apache-2.0 on the kernel does not open the platform.

  • Kernel and manifesto — Apache-2.0. Digest, Gate 1, the epistemic vocabulary, and the charter.
  • Contract snapshot — MIT. Stylus contracts on Arbitrum Sepolia. A showcase, not the live platform.
  • Platform — unpublished. API, frontend, engines, server-side gene executors, production configuration.

Closed

  • Platform source (API, frontend, engines) stays in a private repository.
  • No mainnet deployment. No public SDK. No NFT certificates. No VR/AR labs.
  • diu-docs is not an API and not a documentation tree.
